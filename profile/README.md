# GSMSV

**광주소프트웨어마이스터고등학교 재학생의 공부와 프로젝트 배포를 돕는 교내 인프라 플랫폼입니다.**

교내에서 유휴 상태로 있던 GPU 서버를 Proxmox VE로 묶어 재학생에게 가상 서버와 서버리스 함수를 비용 부담 없이 제공합니다.

> [GSMSV 바로가기](https://gsmsv.site)

## 이용 대상

- **일반 사용자** (GSM 재학생): DataGSM 계정으로 로그인해 인스턴스와 서버리스 함수를 사용합니다.
- **프로젝트 오너** (교내 프로젝트를 맡은 재학생): 가입 신청 후 관리자 승인을 거쳐 사용합니다. 프로젝트 전용 노드와 Custom 사양을 제공하며 인스턴스 사용 기간에 제한이 없습니다.


## 제공 중인 서비스

### 인스턴스 (VM)

Ubuntu 22.04 가상 서버를 웹에서 신청하고 관리합니다.

- **티어**: Basic, Standard, Custom 티어를 제공해 원하는 성능의 인스턴스를 사용할 수 있습니다.
- **전원 제어**: 사용자 스스로 인스턴스의 전원을 제어할 수 있습니다.
- **리소스 모니터링**: CPU, 메모리, 네트워크, 디스크 I/O 그래프를 나타냅니다.
- **스냅샷**: 수동 스냅샷과 매일 자동 스냅샷 기능을 지원합니다.

### 네트워크

- **포트포워딩**: SSH, HTTP 서비스 기본 포트 자동 연결, 커스텀 포트 추가 기능을 제공합니다.
- **HTTPS 도메인**: `{서브도메인}.https.gsmsv.site` 주소로 인스턴스의 웹 서비스를 HTTPS로 공개하는 기능을 제공합니다.
- **방화벽**: 인스턴스 단위 트래픽 허용, 차단 규칙 기능을 제공합니다.

### 서버리스 함수

- JavaScript, TypeScript 함수를 서버 없이 실행하는 기능을 제공합니다.
